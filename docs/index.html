FamQuest

Familienalltag gemeinsam organisieren

FamQuest ist eine selbst gehostete Familien-App für Routinen, Aufgaben, Punkte und Belohnungen. Eine Installation wird von einer Familie genutzt und auf deren eigenem Server betrieben.

Optional können Eltern ein Google-Konto verbinden, um Google Kalender in FamQuest zu verwenden. Der Kalenderzugriff ist auf Lesen beschränkt. FamQuest ändert oder löscht keine Google-Kalenderdaten.
